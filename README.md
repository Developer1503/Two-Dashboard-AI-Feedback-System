# 🤖 Two-Dashboard AI Feedback System

An **AI-powered feedback analysis system** featuring **two interactive dashboards** designed to collect, analyze, and visualize user feedback using modern AI/NLP techniques.

This project is ideal for **academic mini-projects, final-year projects, and portfolio demonstrations** combining AI + dashboard-based UI.

---

## 🚀 Project Overview

The **Two-Dashboard AI Feedback System** provides:

- 📥 **Feedback Collection Dashboard** – for users to submit feedback
- 📊 **Analytics/Admin Dashboard** – for AI-driven insights and visualization
- 🧠 **AI-based Feedback Analysis** – sentiment and textual insight extraction
- 📈 **Visual Representation** – charts, metrics, and summaries

---

## 🧩 System Architecture

User Dashboard ──► Feedback Data ──► AI Analysis ──► Admin Dashboard

---

## 🎯 Key Features

### 🧑‍💻 User Dashboard
- Submit feedback through an intuitive interface
- Text-based feedback input
- Clean and minimal UI

### 👨‍💼 Admin / Analytics Dashboard
- View all collected feedback
- AI-powered sentiment analysis
- Summary statistics and insights
- Visual charts for quick understanding

### 🤖 AI Capabilities
- Natural Language Processing (NLP)
- Sentiment classification (Positive / Neutral / Negative)
- Automated feedback insights

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Developer1503/Two-Dashboard-AI-Feedback-System.git
cd Two-Dashboard-AI-Feedback-System
```
2️⃣ Create Virtual Environment (Optional but Recommended)
```
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```
3️⃣ Install Dependencies
```
pip install -r requirements.txt
```
